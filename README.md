# gif-sticker

文字や写真から、SNSで使える動くGIFスタンプをブラウザだけで作れるオンラインエディター。

公開URL: https://airpocket-soundman.github.io/gif-sticker/

## できること
- 文字スタンプ：日本語フォント10種、ふち・二重ふち・影、単色/グラデ/虹色/チカチカ
- 動き：ぴょんぴょん・ウェーブ・ぶるぶる・どくどく・くるくる・ドーン・タイピング など13種
- 写真素材：自分の写真を読み込んで切り抜き、スタンプ化
  - ✨ AI自動切り抜き（[@imgly/background-removal](https://github.com/imgly/background-removal-js)、初回のみモデルをダウンロード）
  - 背景タップで消す / 四隅から背景をまとめて消す / 消しゴム・復元ブラシ / 反転 / 元に戻す
  - 加工：ポップ・マンガ・モノクロ・セピア・レトロ・ネオン・ネガ・ドット絵、シール風の白ふち
- 出力：128〜480px、透明背景 or 色背景、コマ数（なめらかさ）
- 共有（スマホの共有シートから直接SNSへ）/ コピー / 保存。画像の長押しでもコピーできます

画像はすべて端末内で処理され、どこにもアップロードされません（AI切り抜き時のモデル取得のみ通信します）。

## 仕組み
- `index.html` / `style.css` / `js/*.js` だけの静的ページ（ビルド不要）
- GIFエンコーダは自前実装（`js/gif-encoder.js`：メディアンカット減色 + LZW、1bit透過）
